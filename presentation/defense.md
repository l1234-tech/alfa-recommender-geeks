# Сценарий защиты

Основной интерфейс — React на `http://localhost:8080`. Презентация —
[alfa-course.pdf](alfa-course.pdf).

## Перед показом

1. Если нужен каталог из кейса, [восстановите архив](../data/README.md).
2. Выполните из корня `docker compose up -d --build --wait`.
3. Откройте React и [Swagger](http://localhost:8000/docs) в соседних вкладках.
4. Выполните проверку через nginx. Ожидаемый источник — `database` с
   восстановленной базой или `sample` для демо.

```bash
SMOKE_FRONTEND_URL=http://127.0.0.1:8080 python3 tools/smoke_http.py
```

При занятых портах задайте `ALFA_UI_PORT`, `ALFA_API_PORT` и `ALFA_DB_PORT`
перед запуском. Укажите те же адреса в браузере и в настройках smoke-проверки
`SMOKE_FRONTEND_URL` и `SMOKE_API_URL`.

## Выступление на три минуты

1. **Проблема, 20 секунд.** Предпринимателю нужно быстро выбрать, что изучить
   для текущей задачи и как применить материал.
2. **React, 50 секунд.** Нажмите **Подобрать без уточнений**. Затем выберите
   **Привлечь клиентов** и укажите **Розничная торговля**. Обновите подборку и
   покажите причину рекомендации и следующий шаг на одной карточке.
3. **История, 35 секунд.** В Swagger отправьте
   `POST /api/v1/recommendations` с телом `{}`. Скопируйте `material_id` первой
   карточки. Повторите запрос с телом
   `{"history":[{"material_id":"ВСТАВЬТЕ_ID","event_type":"view"}]}`.
   Покажите, что этот ID исключён. История передаётся через API.
4. **Архитектура, 25 секунд.** React отправляет запрос на свой адрес. Nginx
   передаёт его FastAPI. Backend вызывает движок на метаданных PostgreSQL.
   При запуске без архива работает демо-каталог с явной пометкой.
5. **Оценка и пилот, 50 секунд.** Назовите результаты на 15 тестовых профилях
   из [сравнения](../docs/experiments.md). Для проверки покупок сравните
   персональный подбор и подбор по теме в A/B-тесте 50/50 по пользователям.
   Главная метрика — покупка в течение 7 дней. Дополнительно измеряются
   активные дни, клики, быстрые уходы и задержка API.

## Если спросят об ограничениях

- Ссылка появляется при наличии полного URL из каталога. В дампе есть
  короткие идентификаторы. Причина и следующий шаг доступны в карточке.
- Подписочные курсы представлены карточками и пробными уроками. Подробные
  описания платных материалов скрыты. Закрытые уроки исключаются.
- Офлайн-прогон измеряет релевантность первых пяти рекомендаций на тестовых
  профилях. Влияние на конверсию предстоит проверить A/B-тестом.
