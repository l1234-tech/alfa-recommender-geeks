# React frontend

Из корня, при запущенном FastAPI на localhost:8000:

```sh
cd frontend
npm ci
npm run dev
```

Откройте http://localhost:5173. Требования: Node.js 22.12+ или 24 LTS, npm.
Основной compose раздаёт production React через nginx на http://localhost:8080 и проксирует /api к backend.

## Режимы

Обычный dev — настоящий API, без fallback на mock. VITE_API_BASE_URL пустой: Vite proxy /api → http://localhost:8000. При отдельном origin задайте только origin без /api и настройте CORS на backend. VITE_* публичны, секреты запрещены. Перезапускайте Vite после изменения окружения.
npm run dev:mock явно включает готовые синтетические ответы по marketing/finance/team; остальные поля не персонализируют fixtures. Набор отмечен «Пример подборки».
Настоящий backend со sample-каталогом отмечается «Подборка по учебному каталогу». Для database-каталога такой пометки нет.

## Поведение

Все поля необязательны; «Подобрать без уточнений» отправляет пустой user_profile, history:[], limit:5. Имена и схема: docs/api.md. Выбранные форматы передаются как preferred_formats. Сводка результата — снимок отправленного профиля, правки формы требуют нового запроса.
API-клиент проверяет HTTP, JSON, поля и metadata, отменяет запросы и ограничивает ожидание 12 сек. Новый запрос отменяет предыдущий, поздние ответы игнорируются. reasons показываются текстом, score скрыт. URL допускаются только абсолютные http/https, новые вкладки защищены noopener noreferrer.

## Проверки

```sh
npm run build
npm run typecheck
npm run lint
npm test
```

Для живого HTTP-теста запустите API и dev, затем в PowerShell: $env:VITE_LIVE_API_URL="http://127.0.0.1:5173"; npm test -- src/live.test.tsx. Без переменной live-тесты пропускаются.
Диагностика ошибок/таймаута/пустой выдачи: VITE_ENABLE_DIAGNOSTICS=true только вместе с dev:mock; по умолчанию скрыта, в production недоступна.

## Ограничения

История в UI не собирается и не хранится; backend поддерживает её в запросе. Форматы и значения формы соответствуют sample и нормализации адаптера, схема API принимает строки без закрытых enum. Неизвестная платность не называется бесплатной.
Описание и URL зависят от каталога. Sample-ссылки фиктивны и не выводятся. Относительные ссылки database-каталога без подтверждённого origin не превращаются в рабочие. Результаты обучения не генерируются. Предоставленная БД нужна для проверки содержимого и ссылок настоящих материалов.

## Передача версии
Эта версия основана на локальной integration/react-product, коммит b5cdf19, и текущих frontend-исправлениях. В origin/integration React ещё отсутствует. Простого clone удалённой integration недостаточно: используйте архив исходников этой версии либо передайте локальную ветку после коммита изменений.
Базовый контракт origin/integration поддерживается; description, url, catalog_source и nullable is_paid — расширения локального backend. На исходном backend ссылки отсутствуют, а платность database-каталога может ошибочно приходить как false. Для полной функциональности запускайте backend из того же архива.
Если API не возвращает безопасный URL, переход недоступен: sample содержит синтетические материалы и фиктивные относительные маршруты. Настоящие адреса нужны из Url предоставленного каталога.
