# Вспомогательный Streamlit
Сохранён из origin/feat/ui-streamlit, основной интерфейс — frontend/ (React).
Из корня: python -m pip install -r tools/streamlit/requirements.txt
Затем BACKEND_URL=http://localhost:8000 streamlit run tools/streamlit/streamlit_app.py
В PowerShell задайте переменную через $env:BACKEND_URL. Этот инструмент не запускается основным compose.
