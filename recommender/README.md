# Recommendation Engine

Здесь находится независимая логика рекомендаций.

Предлагаемые модули:
- `data_processing/` — чтение и очистка данных;
- `features/` — признаки пользователя и материалов;
- `algorithms/` — baseline и основной алгоритм;
- `ranking.py` — итоговое ранжирование;
- `explanations.py` — объяснение причин рекомендации.

Согласуйте контракт входных и выходных данных с backend до параллельной реализации.
