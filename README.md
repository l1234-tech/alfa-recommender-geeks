# Alfa Recommender

Персональная рекомендательная система образовательных материалов платформы «Альфа-Курс».

## Цель проекта
Подбирать предпринимателям наиболее подходящие образовательные материалы с учетом:
- стадии бизнеса;
- сферы деятельности;
- текущей задачи;
- опыта пользователя;
- истории взаимодействий (если доступна).

Система должна поддерживать cold start, объяснять рекомендации и предлагать следующий шаг.

## Статус
Проект в разработке. Хакатон: до **16.11.2026, 14:00**.

## Архитектура (план)
- `frontend/` — пользовательский интерфейс (React + TypeScript), зона команды frontend.
- `backend/` — HTTP API (FastAPI), зона команды backend.
- `recommender/` — ML/DS: обработка данных, признаки, ранжирование, объяснения и офлайн-оценка.

## ML handoff
Контракт ML-модуля для коллег, подключающих его к приложению, описан в [docs/ml_handoff.md](docs/ml_handoff.md). Документ фиксирует текущие Python-контракты и рекомендуемый нейтральный формат передачи; он не реализует HTTP API или backend.

## Быстрый старт
Инструкция по запуску всего приложения относится к интеграционной части команды. ML-модуль можно проверять отдельно unit-тестами из корня репозитория:

```bash
python -m unittest discover -s tests -v
```

## Данные
Исходные данные кейса хранятся локально и не коммитятся в репозиторий.
Для тестирования и демонстрации используйте синтетические данные.

## Ограничения
- Не публиковать исходные выгрузки и их копии.
- Не коммитить секреты, персональные данные и сырые пользовательские идентификаторы.
- Для платных материалов не раскрывать закрытое содержание.
- Отсутствие взаимодействия не означает отрицательное предпочтение.
