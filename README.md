# Alfa Recommender

Персональная рекомендательная система образовательных материалов платформы «Альфа-Курс».

## Цель проекта
Подбирать предпринимателям наиболее подходящие образовательные материалы с учетом:
- стадии бизнеса;
- сферы деятельности;
- текущей задачи;
- опыта пользователя;
- истории взаимодействий (если доступна).

Система должна поддерживать cold start, объяснять рекомендации и предлагать следующий шаг.

## Статус
Проект в разработке. Хакатон: до **16.11.2026, 14:00**.

## Архитектура (план)
- `frontend/` — пользовательский интерфейс (React + TypeScript).
- `backend/` — HTTP API (FastAPI).
- `recommender/` — обработка данных, признаки, ранжирование и объяснения.
- `tests/` — тесты алгоритма, API и пользовательских сценариев.
- `docs/` — архитектура, API и результаты экспериментов.

## Быстрый старт
Инструкция будет дополнена после реализации MVP.

Планируемый запуск:
```bash
docker compose up --build
```

## Переменные окружения
Скопируйте `.env.example` в `.env` и заполните необходимые значения.
Не добавляйте `.env`, ключи, токены или исходную выгрузку данных в Git.

## Данные
Исходные данные кейса хранятся локально и не коммитятся в репозиторий.
Для тестирования и демонстрации используйте синтетические данные.

## Проверка
После реализации добавьте сюда пошаговый сценарий:
1. Запуск приложения.
2. Создание/выбор тестового профиля.
3. Получение рекомендаций.
4. Проверка объяснений и следующего шага.
5. Проверка cold start и неполных данных.
