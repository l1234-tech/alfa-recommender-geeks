# Коллаборативная фильтрация

## Почему item-item, а не user-user

Доступны отдельные явные оценки и записи о прохождении курсов/уроков; часть оценок анонимна и не может использоваться для персонализации. Первый эксперимент — item-item CF: материалы связываются, если одни и те же пользователи положительно взаимодействовали с ними.

## Сигналы

В индекс попадают только оценки не ниже 4, подтверждённое завершение урока и подтверждённое завершение курса. Низкая оценка не создаёт положительную связь. Отсутствие события не считается отрицательной обратной связью. Привязка к курсу без признака завершения не считается положительным сигналом.

## Алгоритм

Строится бинарная матрица пользователь–материал. Для пары материалов считается число пользователей, положительно взаимодействовавших с обоими. Сходство — cosine similarity бинарных столбцов:

`sim(i,j) = co_users(i,j) / sqrt(users(i) * users(j))`

Затем применяется significance weighting:

`sim_shrunk = sim * co_users / (co_users + shrinkage)`

По умолчанию пары с менее чем двумя общими пользователями отбрасываются, shrinkage равен 5. Это стартовые параметры, а не обученные значения. Оценка кандидата — среднее сходство с положительной историей пользователя.

Сырые user_id используются только во время построения индекса и не сохраняются в модели. Индекс содержит только агрегированные счётчики и сходства.

## Холодный старт и гибрид

Если у пользователя нет положительной истории или для неё нет совместных соседей, CF возвращает нулевой сигнал. Стратегия `content_cf_hybrid` объединяет контентную оценку и CF с равными весами, когда CF даёт сигнал; иначе сохраняет контентную оценку.

## Временная оценка

Для каждого пользователя CF-индекс строится на событиях всех пользователей, строго предшествующих началу его test-периода. События с одинаковой временной меткой на границе консервативно исключаются. Профиль целевого пользователя строится только по его собственным train events.

## Ограничения

- Бинарная схема не различает силу оценки 4 и 5.
- Минимальная поддержка и shrinkage заданы вручную.
- Оценки и завершения отражают разные типы поведения; далее потребуется отдельная оценка по типам событий.
- UUID материалов предполагаются уникальными между типами сущностей.
