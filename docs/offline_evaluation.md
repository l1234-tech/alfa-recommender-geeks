# Профили пользователей и офлайн-оценка

## Положительные события и temporal holdout
Положительные события: оценки `Value >= 4` и подтверждённое завершение курса или урока. Отсутствие события не считается отрицательной меткой. Порог 4 — гипотеза для проверки.
`temporal_holdout` оставляет последние 20% событий каждого пользователя для теста, сохраняя минимум одно событие в train. Тестовая релевантность хранится по ключу `(item_type, item_id)`. Для CF используются события всех пользователей строго раньше начала тестового периода.

## Метрики
- Precision@K, Recall@K и NDCG@K для общей положительной релевантности.
- Отдельные срезы тех же метрик по типам положительных событий. В каждом срезе учитываются только пользователи с положительным событием данного типа в test.
- Catalog coverage — доля доступных материалов, появившихся хотя бы в одной рекомендации по всем тестовым пользователям.
- Cold-start benchmark — те же ranking-метрики на вручную заданных onboarding-only профилях и ожидаемых релевантных материалах. Это синтетический benchmark, а не оценка реального поведения пользователей.

## Ограничения
TF-IDF пока строится по текущему каталогу, а не историческому снимку. События рейтинга и завершения отражают разные стадии воронки. Синтетические cold-start cases требуют экспертной проверки и не заменяют онлайн A/B-тест.


## Разнообразие рекомендаций (MMR)

В `recommend` можно передать `diversity_weight` от 0 до 1. При нуле сохраняется обычная сортировка по релевантности. При положительном значении применяется жадный Maximal Marginal Relevance:

`MMR = (1 - λ) * relevance - λ * max_similarity_to_selected`.

Похожесть считается по Jaccard между токенами заголовка, описания, тем, тегов, отраслей и типа материала. Релевантность в выдаваемом объекте остаётся исходным score модели, а MMR используется только для выбора порядка. Начинать эксперимент рекомендуется с λ = 0.15, 0.25 и 0.35; выбирать значение следует по validation-метрикам релевантности вместе с оценкой разнообразия.

Это лексико-метаданный прокси похожести, а не семантическая эмбеддинговая модель. Для пустых или неполных метаданных diversity-эффект может быть слабым.
