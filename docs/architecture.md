# Архитектура

## Компоненты
1. Frontend — сбор профиля и отображение рекомендаций.
2. Backend — API, валидация и координация компонентов.
3. Recommendation Engine — признаки, скоринг, ранжирование, объяснения.
4. Data Layer — каталог материалов и события взаимодействий.

## Поток запроса
Профиль пользователя → API → Recommendation Engine → ранжированный список + объяснения → Frontend.

## Важные требования
- Cold start при отсутствии истории.
- Устойчивость к неполным профилям.
- Объяснение каждой рекомендации.
- Следующий шаг для пользователя.
- Не раскрывать закрытое содержание платных материалов.
